# 오키나와 겨울 가족여행 (2026.12.23–27)

아이폰 홈 화면에 설치해서 쓰는 여행 가이드 웹앱(PWA)입니다.

- 일본 시간에 맞춰 '지금 할 일'과 '다음 일정'을 보여 줍니다.
- 위치를 켜면 지금 있는 곳, 다음 목적지까지 거리, 가까운 식당 순서를 보여 줍니다(앱을 열어 둔 동안).
- 일정 항목마다 구글맵 길찾기, '다녀옴' 표시가 있습니다.
- 체크리스트와 '다녀옴' 표시는 휴대폰에 저장되고, Firebase를 연결하면 가족과 실시간으로 공유됩니다.
- 한 번 열면 오프라인에서도 열립니다.

## 설치
1. 아이폰 Safari로 이 사이트를 엽니다.
2. 공유 버튼 → '홈 화면에 추가'.

## 가족 공유 설정
`config.js`의 `firebase` 값에 Firebase 웹 앱 설정을 넣습니다. 가족 공유 코드는 저장소에 넣지 않고, 가족에게 보내는 링크(`?trip=코드`)로 전달합니다.
